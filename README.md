# ОПИСАНИЕ ПРОГРАММЫ - «Торговая лавка Старого Тома»:
    Программа позволяет взаимодействовать с виртуальной витриной магазина. При запуске программы
    открывается меню взаимодействия. Благодаря нему можно как покупать, так и продавать товары торговцу

# ПРИНЦИП РАБОТЫ:
##  1 Прайс-лист - Выводит на экран ассартимент магазина (предметы, их количество и цена). Продавец справшивает, желает ли Игрок купить что-нибудь
        1.1 Да - (Купить) Игрок покупает товар, введя его название и количество
        1.2 Нет - (Вернуться) Выводит стартовый список действий
##  2 Продать товар - При нажатии на эту кнопку, Игроку необходимо ввести Название товара, его количество и цену.
        - Если у Тома уже есть такой товар, но он стоит дешевле, чем товар Игрока, он откажется покупать его.
        - Если товар на продажу закончился, то в очередном меню Название необходимо ввести 0 (Ноль).
        - Проданный товар позже окажется на прилавке у Старого Тома, но уже с более высокой ценой, чем та, за которую он его покупал
##  3 Выход - Завершение программы
